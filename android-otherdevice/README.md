# OtherDevice — 2台のスマホで片方を外部ストレージにする

同一 Wi-Fi (または USB テザリング) 配下にある別の Android 端末に、
自動で AES-256-GCM 暗号化してファイルを送るペアアプリ。

- **sender.apk** — 送信側。選んだファイルを Android Keystore 由来の鍵で暗号化して送信。
- **receiver.apk** — 受信側。HTTP サーバをポート 8787 で立て、
  届いた暗号化バイトを `/sdcard/otherdevice/<送信元の名前>/<ファイル名>.enc` に保存。

## 使い方
1. **受信側のスマホ** に `receiver.apk` を入れて開く。
   - 「ストレージ全アクセスを許可」をタップ → 設定で ON
   - 「サーバを開始」 → 画面に表示される `IP : 192.168.x.y` を控える
2. **送信側のスマホ** に `sender.apk` を入れて開く。
   - 自分の表示名(= 受信側のフォルダ名)、受信側の IP、ポート 8787 を入力
   - 「ファイルを選ぶ」 → 「暗号化して送信」
3. 受信側: `/sdcard/otherdevice/<送信元の名前>/<ファイル名>.enc` に保存される

## 暗号化
- 送信側のみが鍵を持ちます(Android Keystore の AES-256-GCM、エクスポート不可)。
- 受信側は暗号文のまま貯めるだけ(鍵は持たない)。
- ファイル形式: `[1B magic 'O'][1B ver 1][12B IV][AES-GCM 暗号文]`
- **送信側のアプリデータ削除 / アンインストールで鍵が消え、送信済みファイルは復号不可能**。
  (これは設計で、仕様です。復号は送信側端末からだけ可能。)

## 制限
- 現仕様では復号 UI を同梱していません。鍵は Keystore に残っているので、復号 UI を追加するか、
  同じ APK で復号モードを拡張する余地があります。必要なら増築します。
- ネットワークは平文 HTTP ですが、本文は AES-GCM 済みなので傍受されても復号不可。
- Wi-Fi と USB テザリングのどちらでも、両機が同一 L3 ネットワークにいれば動きます。

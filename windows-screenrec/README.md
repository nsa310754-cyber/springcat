# 画面録画 (ScreenRec.exe)

Windows の画面を動画 (AVI) に録画する 1 ファイルのアプリです。インストール不要、外部 DLL なし。

## 使い方
1. `ScreenRec.exe` をダブルクリック
2. 録画する画面・なめらかさ (fps)・画質・動画の大きさを選ぶ
3. **● 録画開始** か **F9** → 3 秒のカウントダウン後に録画開始（画面は通知領域に隠れます）
4. **F9** でもう一度押すと停止、**F10** で一時停止 / 再開
5. 保存先（既定: `ビデオ\画面録画`）に `録画_日付_時刻.avi` ができます

## 仕様
- 形式: MJPEG の AVI。Windows の「メディア プレーヤー」「映画 & テレビ」、VLC などで再生できます
- 音声は録音しません
- 1 ファイル 1.8GB を超えると自動で `_2.avi`, `_3.avi` … に分かれます
- PC が追いつかないときは前の絵を繰り返して、動画の長さを実際の時間に合わせます
- マルチモニター: 画面ごと、またはすべてまとめて録画できます
- 必要環境: Windows 10 / 11 (.NET Framework 4.6.2 以上、標準で入っています)

## ビルド (Linux)
```
./build.sh
```
Mono の `mcs` で .NET Framework 4.6.2 の参照アセンブリに対してビルドし、
自己テストで実際に AVI を作って構造を確認、ffmpeg で再生できるかも確かめます。

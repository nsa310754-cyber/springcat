# `/run` で動かすサンプル

ソースのファイルを端末に保存し、コマンドプロンプトで `/run ファイル` と打つか、
エクスプローラーで長押し →「実行」を選ぶ。

| ファイル | 言語 | おすすめのモード | 内容 |
| --- | --- | --- | --- |
| `blocks.go` | Go | ゲーム | 落ち物ゲーム。文字と色で描き、矢印キーで操作する |
| `blocks.js` | JavaScript | ゲーム | 同じゲームのキャンバス版 |
| `hello.go` | Go | 実行 | `a` と計算結果を出力して `exit 0` |
| `hello.ts` | TypeScript | 実行 | 型付きのコードを変換して実行 |
| `hello.py` | Python | 実行 | MicroPython で実行 |
| `hello.lua` | Lua | 実行 | Lua 5.4 で実行 |

落ち物ゲームの操作: ◀ ▶ 移動 / ▲ 回転 / ▼ 1 段落とす / Space 一気に落とす / P 一時停止 /
R やり直し (Go 版は Q で終了)。

わざと文法を壊して (かっこを 1 つ消すなど) ゲームモードで実行すると、エラーとコードが
画面に表示されるのを確かめられる。

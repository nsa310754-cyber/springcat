# `br` コマンドのサンプル

実行したプログラムから、ほかのアプリの上に表示を出したり、画面を自動で操作したりするサンプル。
どちらもシェルスクリプトで、コマンドプロンプトから `sh ファイル名` で動かす
(エクスプローラーで長押し →「実行」→ 実行モードでもよい)。止めるときは「中断 ^C」。

| ファイル | 内容 | 必要な許可 |
| --- | --- | --- |
| `netspeed.sh` | 通信の速度 (下り / 上り) と Wi-Fi の接続速度を、画面の上に出し続ける | 他のアプリの上に重ねて表示 |
| `autoclose.sh` | 「閉じる」「×」「スキップ」のボタンが出たら自動で押す | ユーザー補助 (+ 表示用に重ねて表示) |

## 準備

1. 設定 → 個人設定 →「自動操作と画面上の表示」で「プログラムからの br コマンドを許可する」をオンにする。
2. 同じ場所のボタンから、「他のアプリの上に重ねて表示」を許可し、ユーザー補助を有効にする。
   ユーザー補助のスイッチが押せないときは、Android の「アプリ情報」(Bionic Runner) の右上 ⋮ →
   「制限付き設定を許可」を先に行う (Android 13 以降、ストア以外から入れたアプリにかかる制限)。

動いているあいだは通知が出る。通知の「停止」で、表示をすべて消して終わる。

## `br` でできること

`br help` で一覧が出る。主なもの:

```sh
br overlay set 名前 "文字" [--x N] [--y N] [--size N] [--color #RRGGBB] [--bg #AARRGGBB]
br overlay hide 名前
br ui dump                 # 画面の部品の一覧 (位置 / 押せるか / 種類 / 文字 / 説明 / 名前)
br ui click "閉じる" "×"   # その文字の部品を押す (無ければ終了コード 1)
br tap 540 1200
br swipe 540 1600 540 400 300
br key back
br net                     # 通信量と速度、Wi-Fi の状態
br kill com.example.app    # アプリを強制終了 (完全に止めるには root が必要)
```

C や Go などのプログラムからは、`br` を外部コマンドとして呼ぶか、環境変数 `BR_API`
(`ホスト:ポート:合言葉`) の窓口へ直接つなぐ。通信の決まりは `native/br.c` の先頭に書いてある。

# Bubble Pop (32bit の exe の確認用のミニゲーム)

Bionic Runner の Wine で、**32bit の Windows の exe** が動くかを確かめるための小さなゲームです。害はありません
(ファイルの読み書きもネットの通信もしません)。

- 下から浮かんでくる泡をタップ (クリック) で割ります。30 秒で何点取れるか。小さい泡ほど点が高い
- 画面のいちばん上に `exe: 32bit / WoW64: yes` と出れば、32bit の exe が 64bit の Windows (Wine の WoW64) の
  上で動いています
- 描画は Windows の標準の GDI だけ (裏の画像に描いてから写すので、ちらつきません)

| ファイル | 中身 |
|---|---|
| `bubble-pop.c` | ソース (日本語の文字は番号で書いてあり、ファイルの中身は ASCII だけ) |
| `bubble-pop-32.exe` | 32bit (PE32・i386) の exe |
| `build.sh` | ビルドのしかた (`i686-w64-mingw32-gcc`) |

## 動かし方

1. X11 の画面の「追加機能」で「Windows のプログラム (Wine)」と「32bit の exe も動かす (試験中)」を入れる
2. 「実行ファイル」で `bubble-pop-32.exe` を選ぶ (またはコマンドプロンプトで `wine bubble-pop-32.exe`)
3. X11 の画面にウィンドウが出たら「タップでスタート」

PC の上の qemu で、アプリと同じ Box64 0.4.4・同じ wine.sh を使って、タイトル・遊んでいるところ・
終わりの画面 (点数) まで動くことを確かめました。

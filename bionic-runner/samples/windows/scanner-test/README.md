# 構造の検査の確認用プログラム (害は無い)

Windows の exe の構造の検査 (`ExeScanner.scanPe`) が、暗号化して中身を隠す「ローダー型」のウイルスの
特徴を見つけられるかを確かめるためのものです。本物のウイルスではありません。

| ファイル | 中身 |
|---|---|
| `scanner-test.c` | ソース。自分のファイルの末尾の目印を探し、VirtualAlloc で「書き込みも実行もできる」メモリを取り、XOR で隠したバイト列を元に戻して呼ぶ。隠してあるのは `ret` (何もせず戻る) の 1 バイトだけ |
| `scanner-test.exe` / `scanner-test-32.exe` | 64bit 版と 32bit 版。末尾に目印 `BIONIC-RUNNER-SCANNER-TEST-OVERLAY` と、暗号化した設定に見立てた乱数のようなデータ (約 6KB) を付けてある |
| `build.sh` | ビルドと、末尾のデータの付け足し (`sudo apt install gcc-mingw-w64-x86-64 gcc-mingw-w64-i686` が必要) |

ファイルを消す・通信する・ほかのプログラムに触る、といったことは一切しません。Wine で動かすと
「隠した命令 (ret だけ) を動かして戻りました」と出て終わります。

構造の検査では、どちらも **10 点 (危険)** になります (メモリの準備 3・末尾のデータ 3・自分を読む 3・TLS 1)。
文字列の検査 (危険なコマンドを探す方) では何も見つかりません。確かめるには、リポジトリの一番上で:

```
tools/run-pe-tests.sh [Wine の x86_64-windows フォルダ]
```

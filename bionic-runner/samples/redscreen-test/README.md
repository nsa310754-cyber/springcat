# 検知テスト用プログラム (無害)

Bionic Runner の検知機能が赤い警告画面を出すことを確かめるためのシェルスクリプト。
**スマホには何もしない。** ファイルの作成・変更・削除、通信、設定の変更は一切せず、
説明と端末の情報 (機種・Android の版・CPU) を表示するだけ。

- ファイル: [`redscreen_test.sh`](redscreen_test.sh) (形式 1: シェルスクリプト、ビルド不要)
- 警告が出る理由: ファイルの中に **EICAR テスト文字列** が入っているため。
  EICAR テスト文字列は、ウイルス対策ソフトが正しく反応するかを確かめるために業界で決められた、
  ただの文字の並び。プログラムとしての働きは持たない。このスクリプトは変数に入れておくだけで、
  実行には使わない。

## 使い方

1. `redscreen_test.sh` を端末に保存する。
2. Bionic Runner の「実行ファイル」(デスクトップなら「プログラムを追加」) で選ぶ。
3. 赤い警告画面「この実行可能ファイルはスマホを破損させる可能性があります」が出る。
4. 「詳細」を押すと、理由「ウイルス検査用のテスト文字列 (EICAR)」が表示され、
   「それでも実行」が出る。
5. 「それでも実行」を押すと実行される。入力欄に次を打つ。

| 入力 | 内容 |
| --- | --- |
| `1` | このプログラムの説明 |
| `2` | 端末の情報 (読み取るだけ) |
| `q` | 終了 |

引数は使わない。

## 注意

- 端末の Google Play プロテクトなど、ほかのウイルス対策ソフトも EICAR テスト文字列に反応して
  警告を出すことがある。それも正常な動作で、このファイル自体は無害。
- 「実行しない (おすすめ)」を押すと、ファイルは登録されずに消える。

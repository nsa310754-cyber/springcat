# Star Catch (サンプル)

Bionic Runner の動作確認用の小さなゲーム。落ちてくる星をカゴで受け止め、爆弾は避ける。
絵 (ゲーム画面)・効果音・タッチ操作・キー入力をまとめて試せる。

- 実行ファイル: [`starcatch.exe`](starcatch.exe) (arm64 / glibc 動的リンク / SDL2 使用)
- 名前は `.exe` だが中身は Linux の ELF。Windows では動かない。
- 画像・音・文字はすべてプログラム内で作るので、ファイル 1 個で動く。

## 遊び方

1. `starcatch.exe` を端末に保存する。
2. Bionic Runner の「実行ファイル」(またはデスクトップの「プログラムを追加」) で選び、
   「登録して実行」を押す。root 権限が必要 (glibc 用プログラムのため)。
3. ゲーム画面が開く。

| 操作 | 内容 |
| --- | --- |
| 画面をタップ / Space / Enter | 開始・再挑戦 |
| 画面をドラッグ / ◀ ▶ | カゴを左右に動かす |
| Esc | 一時停止 |
| ✕ / 戻る | 終了 |

- 黄色い星 +1 (連続で受けるとボーナス)、水色の大きな星 +5、ハートでライフ回復。
- 爆弾を受けるとライフが減り、3 回で終わり。15 点ごとにレベルが上がって速くなる。
- 最高記録は `$HOME/.starcatch_best` に保存される。

## ビルド

```sh
SDL2_PREFIX=/path/to/sdl2-arm64 ./build.sh
```

このツールについて / 対応表

外部サーバや AI API には一切アクセスしません。コードはあなたの端末（ブラウザ）内でトークナイズ（読み取り）され、構文ルールに従って別言語へ書き換えられます。貼り付けたコードが外に送られることはありません。

変換のレベル: これは「構文レベル」のコンバーターです。ブロック構造（インデント⇔波括弧）、制御構文・キーワードの対応、コメント記号、真偽値/null などを変換します。実行意味を100%保証する移植（トランスパイラ）ではありません。整形済みの入力ほど綺麗に変換できます。

  • しっかり変換: JSON ⇔ YAML（正確な相互変換）
  • 構造変換: Python / CoffeeScript / JavaScript / TypeScript / JSX / Java / C / C++ / Go の間（インデント⇔波括弧、キーワード対応）
  • 簡易変換: 上記以外（Ruby / Haskell / HTML など）はキーワードとコメント記号の置換のみ
  • 中継変換: 例 Haskell → HTML → JSX のように多段で変換

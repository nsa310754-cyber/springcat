APK Builder Web

インストール不要。iPhone / iPad の Safari でも、この画面だけで Android アプリ（.apk）を作れます。アプリのインストールもサーバーも要りません。

on-device · APK Signature v2 · no server

iPhone から Android の人へ渡すには： ダウンロードした .apk を、AirDrop・メール・LINE・クラウドなどで Android 端末へ送ってください。Android 側で「提供元不明のアプリ」を許可するとインストールできます。
これは ブラウザで動く簡易版です（HTML→署名付きAPK）。AAB / Google Play 提出用zip / PWAモード / 既存keystoreでの更新 / Firebase・AdMob / APK Analyzer などのフル機能は Android アプリ版に入っています。

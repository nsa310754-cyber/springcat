# 3D プリンコ (Plinko3D)

針と回転する障害物の間をボールが落ちていき、下の 7 つの穴に入ってスコア加算。
現金・課金・通貨要素なし。Three.js + Cannon-es で動く本物の 3D 物理シミュレーション。

- タップした場所の X 座標から新しいボールが落下
- 中央のジャックポット穴 (500) ほか、両端 100、その内側 50、外側寄り 20
- 中段と下段に回転するバー 2 本 (異なる速度で逆回転)
- ボールは最大 40 個までシーンに残る (古いものから消える)

ゲーム本体 (`assets/game/*.html|js`) を WebView で `appassets.androidplatform.net` 配信し、
ES モジュール/テクスチャ生成/物理ステップが同一オリジン制約でブロックされないようにしています。

## ビルド
```bash
cd android-plinko
./gradlew assembleDebug
```

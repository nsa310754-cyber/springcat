Block Destroy v4.0.10 — Windows (x64) 版 / Winlator (Bionic版・glibc版) 対応

■ 遊び方 (Winlator)
 1. この zip を展開し、BlockDestroy フォルダごと Winlator から見える場所に置きます
    (例: 端末の Download フォルダ → Winlator では D: ドライブ)
 2. Winlator のコンテナを起動し、BlockDestroy フォルダの BlockDestroy.exe を開きます
    ・Bionic版 / glibc版 どちらの Winlator でも、同じ BlockDestroy.exe を使います
 3. 初回だけ、日本語・絵文字用のフォントを Wine に入れて自動で1回再起動します (数秒)

■ うまく動かない時
 ・コンテナの Windows のバージョンは Windows 10 にしてください
 ・画面が真っ白のままなら、一度閉じてもう一度 BlockDestroy.exe を開いてください
 ・絵文字は Wine ではカラーで描けないため、白黒で表示されます
 ・ランキングなどのオンライン機能は、インターネットにつながっている時だけ使えます

■ 普通の Windows 10 / 11 の PC でも、そのまま BlockDestroy.exe で遊べます

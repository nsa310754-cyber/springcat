About LunaxOS

🌙 LunaxOS 1.0 "Selene"

A virtual environment for phones that can't run .exe files.

Native Windows programs need an x86 CPU, which your phone browser can't provide — so Lunax ships its own executable format: small programs written in LunaBASIC that really run.

Quick start

• Terminal → run hello.exe
• Files → tap ▶ RUN on any program
• Editor → write LunaBASIC, save as *.exe, hit ▶

LunaBASIC supports

PRINTINPUT IF / THEN / ELSEFOR / NEXT WHILE / WENDGOTO / GOSUB COLORSLEEP RND INT LEN MID$ …

Your files live in this browser (localStorage). Terminal command reset-fs restores the samples.

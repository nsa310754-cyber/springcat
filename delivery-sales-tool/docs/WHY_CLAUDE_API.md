# なぜ Claude（AI）API が必要なのか

このツールは 2 つの外部 API を使います。

| API | 役割 | 一言でいうと |
|---|---|---|
| **X 公式 API** | 投稿を集める | 「データを取ってくる」係 |
| **Claude API（AI）** | 投稿を判断する | 「取ってきたデータを考える」係 |

このドキュメントは、後者の **Claude（AI）API がなぜ必要なのか** を説明します。

---

## 1. 結論

**X API だけでは「投稿の一覧」しか手に入りません。**
そこから **「誰が営業対象か」を判断し、点数をつけ、理由を言葉にし、DM文を書く** ——
この「人間の頭脳に近い作業」をやってくれるのが AI（Claude）API です。

> X API = 情報収集
> AI API = 情報の理解・判断・文章生成

AI が無いと、集めた投稿を人間が一件ずつ読んで判断することになり、ツールの意味がほとんど無くなります。

---

## 2. AI が具体的に担当している 5 つの仕事

このツールで AI が行っている処理です（すべて `src/aiClient.js` に集約）。

### ① 営業対象かどうかの判定
投稿とプロフィールを読んで「この人は配達員で、乗り換え営業の対象になりそうか？」を判断します。

- 例：「今日のUber Eats全然鳴らない…専業きつい」→ **対象**
- 例：「うちのトイプードルかわいい🐩」→ **対象外**

キーワード一致だけでは、配達と無関係な投稿（「配達"ロボット"のニュース」など）も拾ってしまいます。
文脈を読んで人間らしく判断できるのが AI の強みです。

### ② 営業優先度のスコア化（0〜100点）
不満の強さ・配達員である確度・乗り換え意欲などを総合して点数化し、
**優先的にアプローチすべき人から並べられる**ようにします。

### ③ 推定地域
「梅田・難波中心」→ 大阪、「23区内で配達」→ 東京 のように、
明示されていない地域も文脈から推定します。

### ④ 推定利用サービス
「出前館・Uberかけもち」→ 出前館 / Uber Eats のように、現在使っているサービスを読み取ります。

### ⑤ AI 判定理由の生成 ＆ 営業 DM の作成
- **なぜ対象と判断したか**を日本語の文章で説明（人間が最終確認できるように）
- 相手の状況に合わせた**個別の営業 DM 文章**を生成

---

## 3. 「キーワード検索だけ」では不十分な理由

X API のキーワード検索でも投稿は集まります。しかし——

| やりたいこと | キーワード検索だけ | AI があると |
|---|---|---|
| 配達員かどうかの見極め | ❌ 無関係な投稿も混ざる | ✅ 文脈で判断 |
| 優先度づけ | ❌ 並べられない | ✅ 0〜100点で自動ランク |
| 地域・利用サービスの推定 | ❌ できない | ✅ 文章から推定 |
| 判定理由の説明 | ❌ 出せない | ✅ 日本語で提示 |
| 個別DM文章の作成 | ❌ 手書きが必要 | ✅ 自動生成 |

つまり AI は、**「拾う」から「選ぶ・理解する・書く」への引き上げ**を担っています。

---

## 4. AI 無しでも動くが、精度は落ちる

このツールは **ANTHROPIC_API_KEY が未設定でも動作します**。
その場合は AI の代わりに「キーワード出現数で点数をつける簡易ルール」で判定します（`heuristicAnalyze`）。

- ✅ メリット：無料・すぐ試せる
- ⚠️ デメリット：文脈を読めないため誤判定が増え、DM もテンプレート固定になる

**動作確認・デモには十分ですが、実運用では AI API の利用を推奨します。**

---

## 5. Claude でなければダメなのか？（他社AIでも可）

いいえ。ここでの「AI」の役割は他社の生成AIでも代替可能です。

- **Gemini API**（無料枠あり・安価）
- OpenAI API（GPT系）
- など

現在の実装は Claude（Anthropic）を使っていますが、AI 処理は `src/aiClient.js` に分離しているため、
**他社 API への差し替えが容易**です。コスト重視なら Gemini などに切り替える構成にもできます。

> ⚠️ 注意：他社 AI に替えられるのは「AI 判定・DM生成」の部分だけです。
> **投稿を集める X API は AI では代替できません**（別途必要）。

---

## 6. まとめ

- **X API** = 投稿を集める（必須）
- **AI API（Claude 等）** = 集めた投稿を「判断・スコア化・理由づけ・DM生成」する頭脳部分
- AI が無いとツールの中核（自動判定と文章生成）が成立せず、ただの投稿一覧になる
- AI は Claude 以外（Gemini 等）にも差し替え可能

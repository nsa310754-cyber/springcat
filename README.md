# springcat 🐾

アイソメトリック（等角投影）の島を跳ねまわる子猫のブラウザゲーム。

## 遊び方（PC / Android）

`index.html` をブラウザで開くだけ。ビルドや依存関係はありません。

## iPhone / iPad にインストール（PWA）

`.iso` や App Store は不要です。Web公開したURLを Safari で開き、ホーム画面に追加するとアプリとして遊べます。

1. このリポジトリで **GitHub Pages** を有効化（Settings → Pages → Branch: `main` → Save）
2. 数分後に公開される URL（例: `https://<ユーザー名>.github.io/springcat/`）を **iPhone の Safari** で開く
3. 共有ボタン **[ ↑ ]** → **「ホーム画面に追加」** をタップ
4. ホーム画面に 🐱 アイコンが追加され、全画面・オフラインで遊べます

> `.ipa`（ネイティブアプリ）にしたい場合は Apple Developer アカウント（年 $99）と Mac の Xcode が別途必要です。PWA ならどちらも不要です。

- **矢印キー / WASD** … 移動
- **スマホ** … 画面下のボタン、または画面のスワイプ
- 島にある 🐟（魚）をすべて集めるとクリア
- 穴（水）に落ちるとやり直し
- レベルは自動生成で無限に続きます

## 特徴

- Canvas 2D による自作アイソメトリック描画（外部ライブラリなし）
- タイルの高さ・水面・影・ジャンプアーク付きのなめらかなホップ移動
- レベル2以降はマップ自動生成（到達可能性を保証するフラッドフィル付き）
- WebAudio による効果音（アセット不要）
- PC / スマホ両対応
- PWA 対応（manifest + Service Worker）でホーム画面インストール・オフライン動作

## 🌙 Lunax — a virtual environment app for phones

Can't run `.exe` files on your phone? [`lunax/`](./lunax) is a self-contained
web app that boots a tiny virtual OS (**LunaxOS**) with a real console and lets
you **select and run programs** — its own `.exe` format powered by a built-in
LunaBASIC interpreter.

Open [`lunax/index.html`](./lunax/index.html) in any browser. See
[`lunax/README.md`](./lunax/README.md) for details.

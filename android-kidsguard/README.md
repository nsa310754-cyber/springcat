# 安心フィルター (KidsGuard)

子ども向けの Android アプリブロッカー。保護者がブロックしたいアプリを選ぶと、
その子がそのアプリを開こうとするたびに全画面のブロック画面が出てホームへ戻します。
本アプリ自体は 4 桁 PIN で保護され、設定を子どもが変えられないようにします。

## 使う権限と理由
| 権限 | 目的 |
|---|---|
| デバイス管理者 (`force-lock` のみ) | アプリ本体を勝手にアンインストールされないようにする。ワイプや画面ロック変更はしません。 |
| 使用履歴アクセス | 前面に出ているアプリの判定(予備) |
| ユーザー補助 (アクセシビリティ) | 前面アプリをリアルタイム検知してブロック画面を出す |
| 他のアプリの上に重ねて表示 | ブロック画面をどの画面の上にも出せるようにする |

## 画面の流れ
1. **初回起動** — 4桁 PIN を設定
2. **メイン画面** — 必要な権限を順に有効化 → 「ブロックするアプリを選択」で対象をチェック
3. **以後** — ランチャから本アプリを開くたびに PIN 入力
4. **子ども利用時** — ブロック指定されたアプリを開くと全画面ブロック → ホームへ

## ビルド
```bash
cd android-kidsguard
./gradlew assembleDebug
# → app/build/outputs/apk/debug/app-debug.apk
```

`gradlew` は本リポジトリの `android/gradlew` と同じ Gradle 8.x 相当を想定しています。
手元のラッパーが無ければ `gradle wrapper --gradle-version 8.9` で生成してください。

## 制限 / 注意
- アクセシビリティに依存するため、OS によっては一定期間使わないと権限が外されます。
- ブラウザのような 1 つのアプリ内で複数サイトを開くタイプは URL 単位の制御まではしません(アプリ単位の ON/OFF)。
- デバイス管理者を解除してからでないとアンインストールできません。本アプリ内の「デバイス管理者を解除」からどうぞ。
- PIN は端末内に SHA-256 ハッシュで保存され、サーバ送信は一切しません。忘れた場合はアプリデータの削除が必要です。

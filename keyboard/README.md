# SpringKey — 端末をつないで使うソフトウェアキーボード＋マウス

「キーボードが無いとき、2台の端末をつないで、片方に表示したキーボードでもう片方を操作する」ためのアプリです。
ブラウザではなく **ネイティブ Android アプリ 2種** で作ってあります。

| アプリ | 役割 | パッケージ |
|--------|------|-----------|
| **SpringKey 送信**（つなげる方＝キーボード側） | 画面にキーボード＋テンキー＋トラックパッドを表示し、入力を送る | `site.ragdollp.springkey.controller` |
| **SpringKey 受信**（つながられる側） | 入力を受け取り、この端末を実際に操作する（文字入力・マウス） | `site.ragdollp.springkey.receiver` |

APK（署名済み・そのままインストール可）:

- `dist/SpringKey-Controller-1.0.apk` … 送信（キーボード側）
- `dist/SpringKey-Receiver-1.0.apk` … 受信（つながられる側）

---

## できること

- **本物に近いキーボード**：ファンクション行（Esc / F1–F12）、数字行、QWERTY、
  修飾キー（Shift・Caps・Ctrl・Alt・◆(Win/⌘)）、矢印キー、そして **豪華フルテンキー**
  （NumLock・`/ * - +`・`Enter`・`.`）。Shift/Caps で大文字・記号が切り替わります。
- **マウス付き**：トラックパッドをなぞってカーソル移動、タップで左クリック、
  ボタンで左/中/右クリック、右のバーでスクロール。受信側の画面には
  オレンジのマウスカーソルが出て、実際にタップ・スワイプします。
- **言語（配列）を変更できる**：
  - 🇺🇸 US QWERTY / 🇯🇵 日本語 JIS（かな併記）/ 🇩🇪 ドイツ QWERTZ / 🇫🇷 フランス AZERTY
  - UI 言語も 日本語 / English で切り替え可能。
- **つなぎ方いろいろ**：同じ Wi‑Fi、相手のホットスポット、USB テザリングなど、
  両端末が同じネットワークにあれば OK（TCP で接続）。

## 使い方

### ① 受信側（操作される端末）
1. `SpringKey-Receiver-1.0.apk` をインストールして起動。
2. 画面に出る **IP アドレス / ポート / PIN** を確認。
3. **「サーバーを開始」** を押す。
4. 初回のみ、下の2つを有効化：
   - **① キーボード設定** → SpringKey をキーボードとして ON にし、
     **② 入力方法を選ぶ** で SpringKey に切り替え（文字を入れたいアプリのテキスト欄をタップ）。
   - **③ アクセシビリティ設定** → 「SpringKey 受信」を ON（マウス操作に必要）。

### ② 送信側（キーボードを表示する端末）
1. `SpringKey-Controller-1.0.apk` をインストールして起動。
2. 右上の **「接続」** を押し、受信側に出ていた **IP・ポート・PIN** を入力して接続。
3. あとはキーボードを打つ／トラックパッドを操作するだけ。受信側の端末が動きます。
4. 右上のセレクタで **配列（言語）** と **UI 言語** を切り替えられます。

## つなぎ方（ネットワーク）の例

- **同じ Wi‑Fi**：両方を同じ Wi‑Fi に接続 → 受信側の IP を送信側に入力。
- **相手のホットスポット**：受信側（または送信側）のテザリングをオンにして、もう一方を接続。
- **USB テザリング**：受信側の USB テザリングを PC/端末経由で共有し、同一ネットワークにする。

> 物理的な USB HID として振る舞うわけではなく、ネットワーク（TCP）で入力イベントを送ります。
> そのため相手側にも受信アプリを入れる構成になっています。

## 仕組み

```
[送信アプリ]  WebView(keyboard.html) → JSブリッジ → TCP(7777) ┐
                                                              │ 行区切りJSON
[受信アプリ]  TCPサーバ → InputDispatcher ┬→ IME(文字入力) ←─┘
                                          └→ アクセシビリティ(カーソル/タップ/スクロール/戻る)
```

送受信するメッセージ（1行1JSON）:

| 種類 | 例 | 動作 |
|------|-----|------|
| 文字 | `{"t":"txt","s":"a"}` | フォーカス中のテキスト欄へ入力 |
| 特殊キー | `{"t":"key","k":"backspace"}` | Enter/Tab/矢印/Home 等 |
| ショートカット | `{"t":"shortcut","keys":["ctrl","c"]}` | Ctrl+C など |
| ナビ | `{"t":"nav","k":"back"}` | 戻る/ホーム/履歴 |
| マウス移動 | `{"t":"m","dx":5,"dy":-3}` | カーソル相対移動 |
| クリック | `{"t":"click","b":"right"}` | 左/中/右（右＝長押し） |
| スクロール | `{"t":"scroll","dx":0,"dy":40}` | スワイプ |

- 文字入力は **IME** を優先し、使えない場面ではアクセシビリティで代替入力します。
- マウスカーソルは `TYPE_ACCESSIBILITY_OVERLAY` で表示するので「他アプリの上に表示」権限は不要です。

## ビルド方法

Android SDK（compileSdk 34 / build-tools 34）と JDK 17 が必要です。

```bash
cd keyboard/android
# local.properties に SDK パスを設定（例）
echo "sdk.dir=$ANDROID_HOME" > local.properties

./gradlew :controller:assembleRelease :receiver:assembleRelease
# → controller/build/outputs/apk/release/controller-release.apk
# → receiver/build/outputs/apk/release/receiver-release.apk
```

APK は debug 署名で出力されます（そのまま端末にサイドロード可）。配布用は各自の鍵で署名してください。

---

## 注意 / 制限

- 受信側の **文字入力には IME 選択**、**マウス操作にはアクセシビリティ許可** が必要です（Android の仕様）。
- 端末メーカーによってはアクセシビリティのジェスチャに制限がある場合があります。
- 同じネットワークに繋がっていることが前提です（別ネットワーク越しの利用は想定していません）。
- 平文 TCP + PIN の簡易認証です。信頼できるネットワークで使ってください。
